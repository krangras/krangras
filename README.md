## Проекты

### [FixRate AI](https://github.com/Fir-White/FixRateAI) · текущий командный проект

Сервис для инженеров и техников, которые планируют и выполняют обслуживание оборудования. Объединяет реестр, регламенты, календарь, задания и фотоотчёты. Инженер видит, что пора обслужить, кому назначена работа и что уже принято. ИИ-помощник помогает найти данные, разобрать Excel и подготовить изменения для подтверждения.

**Мой вклад.** Веду командную интеграцию, работаю со схемой PostgreSQL и историей обслуживания. Развиваю ИИ-помощника и его сценарии работы с данными и подтверждением изменений.

### Buddy System UrFU

Веб-сервис и Telegram Mini App для сопровождения иностранных студентов УрФУ. Команды волонтёров видят предстоящие приезды, распределяют наставников и отслеживают обращения студентов.

**Мой вклад.** Дорабатывал кабинет волонтёра и регистрацию студентов, адаптировал интерфейс для телефонов и Telegram Mini App. Исходный код проекта закрыт.

### WaveScan

ИИ-анализатор логов кибербезопасности. Интегрировал AI Tunnel, находил по 2–3 бага за тестовый прогон и вместе с бэкенд-разработчиком работал над метриками.

### Сайт для подготовки к экзаменам

Изучил, с чем студенты сталкиваются при подготовке, и с помощью LLM разработал и запустил сайт. Им воспользовались **100 уникальных пользователей**.
